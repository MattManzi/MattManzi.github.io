# Mattia Manzi — Siti web & sviluppo

Portfolio statico in italiano. Contiene Canestrini Wine, Malta Parties e BossBabe.
Design monocromatico con fondo antracite, titoli serif e illustrazione originale.

## Utilizzo

Apri `index.html` per vedere il sito. Per pubblicarlo, carica tutti i file e la cartella `assets` mantenendo la struttura. Non servono dipendenze o un comando di build. Su un hosting statico la directory da pubblicare è la radice del progetto.

## File

- `index.html`: contenuti e struttura
- `styles.css`: grafica e layout responsive
- `app.js`: menu mobile, dettagli progetto e copia email
- `favicon.svg`: icona
- `assets/canestrini.jpg`: immagine del progetto Canestrini, fornita dall’utente

Font di sistema Georgia, Arial e Helvetica. Nessuna dipendenza da font esterni.
La foto Canestrini viene mostrata in scala di grigi tramite CSS.
Il progetto Canestrini è indicato come in fase di finalizzazione.
